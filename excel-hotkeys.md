# Горячие клавишы Excel

 | Сочетание клавиш                   | Действие                                    |
 |------------------------------------|---------------------------------------------|
 | `Shift + Space`                    | Выделить строку                             |
 | `Ctrl + Space`                     | Выделить столбец                            |
 | `Ctrl + Minus`                     | Удалить ячейки / выделенную строку          |
 | `Ctrl + Plus` \ `Shift + Ctrl + =` | Вставить ячейки (вставить строку / столбец) |
 | `Ctrl + 1`                         | Формат ячеек (выделенных)                   |
 | `Ctrl + !` \ `Ctrl + Shift + 1`    | Установить числовой формат                  |
 | `Ctrl + #` \ `Ctrl + Shift + 2`    | Установить форматы даты                     |
